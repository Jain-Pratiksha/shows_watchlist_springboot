# shows_watchlist_springboot
A full-stack Spring Boot 3 application that allows users to manage a personal watchlist of shows (movies, series, TV shows). The app features secure login, JWT-based authentication, and role-based authorization for users and admins.

Please check out the below links for individual understanding of Json Web Token (jwt), swagger, logging with logback
