# shows_watchlist_springboot
A full-stack Spring Boot 3 application that allows users to manage a personal watchlist of shows (movies, series, TV shows). 
The app features secure login, JWT-based authentication, and role-based authorization for users and admins.

In this project branch you'll find logback setup.
There is no security filter here in this branch just to make it logging specific.
You can check out this link for advance logging setup:
https://github.com/Jain-Pratiksha/SpringBoot/tree/master/logs
